# KP Portfolio — V2

Swiss Editorial + Modern Tech Minimal redesign.

## Setup
```bash
npm install
npm run dev
npm run build
```
Netlify: build command `npm run build`; publish directory `dist`.

## Content
- Home: `src/pages/[...path].astro`
- Resume: same file, resume section; original uploaded PDF is intentionally NOT included to protect personal information
- Articles: `src/content/articles/en` and `/th`
- Shared navigation and footer: `src/layouts/Base.astro`
- Styles: `src/styles/global.css`

## Review before publication
The homepage project images are illustrative crops from a design mockup, not verified client deliverables. Replace with approved screenshots. Contact email is a placeholder. The original resume PDF is excluded for privacy; create a sanitized public CV separately if desired. Project summaries are based on the supplied resume; verify client approval before publishing detailed project information.
